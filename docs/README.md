# Specdest Website Documentation

Use these documents as the source of truth for website work. For SEO status or next actions, **start with `seo-status-and-todo.md`**:

- `website-decisions.md` — consolidated implementation decision record. Read this first; it captures the current approved navigation, interaction, content, visual, image, architecture, and deployment decisions.
- `new-thread-handoff.md` — short handoff for future chats and for reusing the system on another company website; explicitly separates reusable rules from Specdest-specific decisions.
- `website-direction.md` — brand, positioning, information architecture, visual direction, motion, content, and case-study principles.
- `architecture.md` — React/Vite static-first architecture, prerendering, SEO, navigation behavior, and Firebase Hosting decisions.
- `seo-status-and-todo.md` — current completed/pending/blocked status, owner, occasional-work checklist and next SEO/external-presence actions.
- `commercial-seo-keyword-map.md` — commercial keyword-to-URL ownership, GSC query signals, and measurement limitations.
- `seo-authority-and-case-proof.md` — case-study evidence/approval gaps, vetted directory candidates, and off-site authority tracking.
- `seo-anonymous-cases-and-listings.md` — anonymous case-study precedents, Japanese and international directory shortlist, profile copy, and personal-information publication safeguards.
- `../public/images/README.md` — image folder map, replacement workflow, and size policy.
- `../public/images/reference-sources.json` — provenance/source metadata for temporary reference images.

Before changing the website, preserve these decisions unless explicitly superseded.
